SA-AKI 28-Day In-Hospital Mortality Risk Calculator

Sepsis-associated acute kidney injury · variables within 0–24 h of ICU admission · machine-learning model + simplified integer scorecard

Patient inputs

Enter values measured within the first 24 h of ICU admission. BUN/Cr is calculated automatically from BUN and creatinine. All calculations run locally; no data are uploaded.

Complete all fields to calculate risk.
Model: Gaussian process classifier (25 features), ABscore-selected best model; bedside scorecard (10 variables, 0–34 points). Benchmark AUROC (temporal holdout / eICU-CRD external model-selection cohort): ML 0.760 / 0.716; scorecard 0.706 / 0.667.
Disclaimer: research and educational use only; not medical advice. Final decisions must be made by clinicians.
Runtime: serve this directory over HTTP (for example python -m http.server 8000) or deploy to GitHub Pages; opening via file:// cannot load the model files.
